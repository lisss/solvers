╔═══════════════════════════════════════════════════════════════════════╗
║                    LOAD BALANCING ALGORITHM                           ║
╚═══════════════════════════════════════════════════════════════════════╝

When a new request arrives:

1. GET all agents with available capacity
2. FIND agent with MOST free slots
3. ASSIGN request to that agent
4. UPDATE agent's current_requests list
5. RETURN request with assigned_agent_id

When a request is completed:

1. UPDATE request status to "completed"
2. REMOVE request from agent's current_requests
3. FREE up agent capacity for new requests

╔═══════════════════════════════════════════════════════════════════════╗
║                        API ENDPOINTS                                  ║
╚═══════════════════════════════════════════════════════════════════════╝

AGENTS:
  POST   /agents              → Create new agent
  GET    /agents              → List all agents
  GET    /agents/{id}         → Get specific agent
  DELETE /agents/{id}         → Delete agent

REQUESTS:
  POST   /requests            → Create and auto-assign request
  GET    /requests            → List all requests
  GET    /requests/{id}       → Get specific request
  POST   /requests/{id}/complete → Mark request as complete

STATISTICS:
  GET    /stats               → Get system statistics

DOCUMENTATION:
  GET    /docs                → Swagger UI (interactive)
  GET    /redoc               → ReDoc (alternative docs)
