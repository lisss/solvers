# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-24

### Added
- Initial release
- FastAPI backend with RESTful API
- React + TypeScript frontend
- Agent management system
- Intelligent load balancing algorithm
- Request creation and tracking
- Request completion workflow
- Real-time statistics dashboard
- Docker and Docker Compose support
- Vercel deployment configuration
- GitHub Actions CI/CD pipeline
- Comprehensive documentation
- Auto-refresh dashboard (3-second interval)
- Beautiful, responsive UI design
- In-memory data storage

### Features
- Create agents with configurable capacity
- Automatic request routing to most available agent
- Complete requests to free agent capacity
- Real-time system statistics
- Mobile-responsive design
- Dark/light theme support (system preference)
- CORS support for cross-origin requests
- Interactive API documentation (Swagger UI)

### Documentation
- README.md with complete setup instructions
- QUICKSTART.md for quick setup
- ARCHITECTURE.md with system design details
- VERCEL_DEPLOYMENT.md for cloud deployment
- CONTRIBUTING.md with contribution guidelines
- CHANGELOG.md for tracking changes

### Development
- Setup scripts for Unix (setup.sh) and Windows (setup.bat)
- Docker configuration for containerized deployment
- Environment configuration templates
- .gitignore and .dockerignore files
